# ONJ-TRUST-03 expiration proof

This append-only package records the privacy-safe technical attestation and the owner's bounded acceptance of one historical short-option expiration lifecycle. Exact broker identities, contract details, dates, economics, raw evidence, reviewed instruction, rehearsal database, and logs are retained in the private evidence bundle outside Git.

The technical evidence path is **PASS**. The project owner's explicit acceptance is recorded in `public/owner-acceptance-v1-attestation.json` and is limited to this bounded expiration case. It does not change PNL-01 or establish general financial correctness, and it authorizes no real database, migration, provider, production, commit, or push action.

The retained broker event was description-derived and was manually reviewed against the exact contract, opening execution/accounting evidence, expiration quantity, zero cash, dates, and absence of successor evidence. The fill-derived episode projection is not event-aware and remains a recorded limitation.

`public/owner-acceptance-readiness-v1.json` records that the private
permission gate was closed before owner review. The acceptance is append-only:
the historical technical assessment remains unchanged with `owner_sign_off: false`,
and the fill-derived episode projection remains not lifecycle-event-aware.
The existing PNL-01 scope record also records that no real exercise example is
represented in the retained historical evidence; synthetic exercise tests are
not historical evidence.
